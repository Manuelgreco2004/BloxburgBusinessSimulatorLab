# BloxburgBusinessSimulatorLab

This will serve as a explanation for any individual to access this repository. This is Bloxburg Business Simulator, a program that runs different business and addresses the names, owners, and funds established, along with cataloguing employees.

Method overloading is used in Business.java in multiple parts, for the business methods, and the display methods in different classes. 

Two separate reasons it works for each method; for the business methods, the this statements had been integrated in each format differently. For the display methods, it was through instantiating in different classes, such as pizzaPlace.display() and pizzaEmployee.display().

The static fields on the other hand, reads static attributes, and do not run int, double, or String data types unless it is with one. Rather, the static fields tells the program that it is 'owned' by the class itself. Take Business.getTotalBusinesses() for one, the class addresses a static method and in turn, returns the total amount of businesses created.
